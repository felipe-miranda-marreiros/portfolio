Toggle

A segmented control with exactly one option chosen, in every state on both themes: the theme switch, whose options are pressed buttons, and the language toggle, whose options are links to the Page in each language, the current one marked. The last row responds to the pointer and the keyboard; its language links reload this page, which has no other language.
