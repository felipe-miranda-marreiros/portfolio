Bilingual field

One Content field in English and Brazilian Portuguese side by side, built from the Text field. A missing translation carries a Missing tag and a dashed edge; it isn't an error, so the Draft still saves and Publish waits for it. Every state on both themes, with placeholder words. The CMS only, so there is no About me version. The fields respond to the pointer and the keyboard.
