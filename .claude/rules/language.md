# Language

English is the main language of this project.

- Write everything in English: code identifiers, comments and JSDoc, commit messages, branch names, issue and PR titles and bodies, and documentation (`CLAUDE.md`, rules, READMEs).
- Another language is allowed only as content that is explicitly meant to be in it, such as a translation or localized site copy. Keep that content separate from code and docs, and keep its keys and identifiers in English.
- Use clear, plain English; don't mix languages within a sentence or identifier.
